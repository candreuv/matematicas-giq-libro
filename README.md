# matematicas-giq-libro

Material gráfico del libro **Matemáticas I – Grado en Ingeniería Química (UPV)**, publicado en LibreTexts Español.

- `gifs/<sección>/`: animaciones de cada sección del libro. El primer fotograma es la imagen final, para que el PDF compilado muestre el dibujo completo.
- `gifs/manifest.json`: correspondencia entre cada GIF y su sección.
- `scripts/manim/`: scripts de [Manim](https://www.manim.community/) que generan las animaciones (`mkgif.sh archivo.py Escena salida`).
